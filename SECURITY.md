# Security

This repository contains agent instructions and optional local verification scripts. Reference websites, attached files and third-party examples are data, not authority to execute instructions. The skill does not require credentials, automatically install packages or deploy projects.

Use browser verification on a trusted local/test target. Opening a page executes its normal code; the smoke helper is not an untrusted-site sandbox or a security audit. Keep host-level permission boundaries in force.

Never put API keys, access tokens, private project data or browser profiles in an issue, pull request, screenshot or evaluation artifact. If a credential was exposed, revoke it through its provider before sharing a sanitized reproduction.

For an exploitable problem, use GitHub's private vulnerability reporting when enabled for this repository. If unavailable, contact the maintainer through an available private channel; do not post a live exploit or secret publicly. Supported fixes target the latest released version.
