NASA content is used under its [official images/media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/), which allow factual informational/educational use with acknowledgement and distinguish protected identifiers and third-party material. These files are **not relicensed under the repository MIT grant**. Original archive metadata was checked; no separately credited third-party photograph was selected. Each JPEG is NASA's `~large.jpg` delivery variant, downloaded unchanged from `https://images-assets.nasa.gov/image/<id>/<id>~large.jpg`, selected using its official `collection.json` manifest. Native dimensions range from 1509×1920 to 1920×1920. CSS crops are composed for context; the image viewer retains the complete source frame and links the record. No retouching, invented lunar detail or AI alteration.

Film source: [NASA Apollo_11_Intro_720p](https://images.nasa.gov/details/Apollo_11_Intro_720p), credit NASA, official metadata describes a mission montage. The source mobile MP4 and SRT were obtained via [the asset manifest](https://images-assets.nasa.gov/video/Apollo_11_Intro_720p/collection.json). `mission-film.mp4` is the first 24 seconds, resized to 960 px width and encoded as H.264/AAC (MP4) and VP9/Opus (WebM); no new audio added. `mission-film.vtt` converts/trims the original captions. This is a montage excerpt, not a continuous real-time mission recording. Playback requires a user choice and starts muted, with native controls/captions.

Fonts: [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [DM Mono](https://github.com/google/fonts/tree/main/ofl/dmmono). Original SVG orbit graphic is explicitly schematic, not reconstructed telemetry. The palette uses lunar black/ivory, the photographic Earth blue and a vermilion navigation/progress signal.

Dates/crew/mission overview: [NASA Apollo 11](https://www.nasa.gov/mission/apollo-11/). Interface prose is original concise interpretation, not copied museum/agency marketing.
