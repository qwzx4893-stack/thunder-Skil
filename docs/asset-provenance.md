# Asset provenance

The current README uses original code-authored artwork in `assets/brand/`: an editable HTML cover, a board composed from actual project captures, a workflow SVG and a prepared sharing image. Typography uses the Apollo study's bundled OFL fonts. Screenshot media keep the [study's original source terms](expressive/apollo/ASSETS.md); the presentation layout and original lightning geometry are MIT project artwork. See [artwork sources and export notes](../assets/brand/README.md). The earlier generated banner remains historical and is described below.

`assets/thunder-skil-banner.png` is an original AI-generated repository banner, created with the built-in image-generation tool for this project on 16 October 2026. It is not copied from a reference website. A JPEG export may be supplied for README/social-preview delivery; the artwork is unchanged.

Final generation prompt:

> Use case: ads-marketing. Create a finished, exceptionally crafted GitHub repository banner for an open-source web design agent skill named THUNDER SKIL. Wide horizontal composition around 2:1, suitable both as a README hero and GitHub social preview, all important content safely within the central 80%. Exact main text: “THUNDER SKIL” (single L in SKIL). Exact small subtitle: “Design with intent. Build with evidence.” Art direction: bold contemporary Swiss editorial typography meeting a physical lightning-cut composition. Deep graphite background with subtle real paper texture, oversized precise warm-white grotesk lettering, a single vivid electric amber lightning incision that reveals aligned cream layers and a few restrained geometric construction marks. Strong confident hierarchy, remarkable negative space, premium printed-poster craft, beautiful optical alignment. The lightning should feel designed and tangible, not a stock thunderstorm photo. Typography is the dominant visual; the abstract lightning mark supports the name. No fake UI, no cards, no badges, no metrics, no company logos, no purple/cyan gradients, no watermark, no extra text. Crisp text at small README width, sophisticated texture, polished final artwork.

The lettering and subtitle were visually inspected after generation. The simple `assets/thunder-mark.svg` is original code-native geometry for the skill's optional host icon. Earlier benchmark artifacts use original code and supplied demonstration metadata without third-party image/font files. The 0.5.1 asset-led showcases deliberately bundle two sourced images and delivery derivatives, with full attribution and rights in [the showcase asset ledger](examples/ASSETS.md). Research-site assets and private prompt corpora are not included.
