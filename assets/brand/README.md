# Repository artwork

`index.html` is the editable source for the cover (1600 × 680), study board (1600 × 1020) and sharing artwork (1280 × 640). Export each named section after local fonts and images finish loading. All PNGs use the section's native dimensions. `workflow.svg` is standalone original vector artwork.

The study board uses actual project captures. Some panels show labeled excerpts, not additional implemented pages. NASA media and local OFL fonts retain the terms in [the study ledger](../../docs/expressive/apollo/ASSETS.md). Original layout, lettering composition and lightning geometry are project artwork under MIT. No award or third-party endorsement is claimed.

`social-preview.png` is a prepared sharing image. Uploading it through the repository's Settings → General → Social preview is a separate GitHub setting; merely adding the file does not activate it.
