# Changelog

## 0.5.0 — 2026-10-16

- Introduced Thunder Skil as the public repository/display name while retaining immersive-web-studio as the compatible runtime identifier.
- Reworked the core around route-specific reading and a useful first slice; added composition-study for content-led hierarchy, evidence and action.
- Reviewed current official OpenAI, Anthropic and Agent Skills authoring guidance alongside SkillsBench, SkillAxe and a recent authoring paper; recorded scope and limits in docs/research.md.
- Extended evaluation guidance with positive/negative selection cases, actual reference-use inspection and failure-driven minimal corrections.
- Reviewed a user-contributed Design OS v2 draft and adapted stable data identity, camera-path/framing checks and explicit tool handoff assumptions into existing conditional references; rejected contradictory blanket rules and unverified benchmark claims.
- Added public documentation, original banner/icon, optional Codex UI metadata, GitHub community templates, pinned CI and deterministic dependency-free release packaging.
- Published checks and bounded development comparisons separately from subjective taste and broad superiority claims. See docs/benchmarks/README.md.

## 0.4.0 — 2026-10-16

- Added a concrete precedent-to-implementation method: matched original-site observation, relationship map, transfer contract, focused study and rendered keep/revise/discard decision.
- Made that method part of substantial open-direction work without imposing research quotas on local fixes or overriding a supplied reference.
- Added six dated first-hand cases: Lusion, Evervault, Apple AirPods Pro, Pentagram, B&O A9 and Sociotype, including wide/narrow observations, actual interaction results and explicit limits.
- Added a worked ceramic-collection transfer showing useful adaptation, rejected copying, asset dependencies and observable failure conditions.
- Corrected reliance on stale extracted systems: the inspected Evervault page differs from the earlier Refero reconstruction. Separated observation from design inference and causal claims.
- Retained anti-slop, task, accessibility and motion guidance. No third-party site code, photography or private prompts redistributed.

## 0.3.0 — 2026-10-16
