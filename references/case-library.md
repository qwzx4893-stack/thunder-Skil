# Mechanisms to adapt, with costs

Load when a concrete implementation example would resolve a direction. These are possibilities, not a menu that chooses the brand. Reference fidelity and product conventions can justify other answers.

For mechanisms grounded in inspected original websites read references/observed-cases.md. Use references/precedent-lab.md to transfer a relationship into the target content; this table alone is not research or a direction.

| Mechanism | Use when | Cost / alternate / check |
|---|---|---|
| Type forms the grid | A name, statement, or number genuinely leads | Needs robust wrapping and language coverage; static; inspect narrow view and enlargement |
| Sticky index | Parallel chapters/specs need orientation | Second navigation to maintain; simplify on narrow screens; keyboard/active section agree |
| One grid violation | Tension supports subject | Needs alignment elsewhere; static; distinguish intention from clipping |
| Split narrative | Material and claim need comparison | Re-compose into a readable mobile sequence; motion-off keeps argument |
| Editorial ledger | Records and comparison dominate | Needs actual data and labels; do not force into every premium site |
| Masked line reveal | A statement deserves a pause | Selectable semantic text, successful-init gating, static reduced path |
| Pin and progress | A real sequence benefits from control | Short meaningful scene initially; alternate sequential path; inspect each state and mobile |
| Depth/parallax | Spatial relation carries meaning | Layers and frame budget; static equivalent; inspect crop and pointer/touch behavior |
| Shader media plane | Material response is a subject cue | Decode/GPU/support costs; poster fallback; inspect actual moving pixels |
| Cursor instrument | Inspection/precision is a task | Fine pointer enhancement only; same information via keyboard/touch |
| Marquee | Real sequential content benefits from movement | Pause/stop affordance where required, static reduced path; never fabricated proof |
| Shared element transition | An object persists across states | Immediate navigation fallback and interruption; verify back/reduced motion |
| Duotone or grain | Material identity genuinely benefits | Rendering cost and product-color truth; can be omitted |
| Data-driven visual | Actual data relationships should be felt | Equivalent labels/table, truthful units/scales, failure/empty state |
| Dense task workspace | Users compare/act on many objects | Clear status/action grouping; responsive alternatives; no compulsory oversized hero |
| Deliberately still surface | Reading or precise work dominates | Strong hierarchy and focus feedback; full motion-quality credit when fit |

For every selected mechanism record purpose, implementation, cost, fallback, and evidence. Combining several examples does not automatically create a coherent direction. Remove a mechanism when comprehension improves without it.
